# 💫 About Me:
⚡ I'm Shahriar, a computer engineering student at KUT with a deep passion for **AI, Computer Vision, and IoT**. I love bridging the gap between software and hardware to build intelligent, real-world systems. My journey is driven by curiosity and a constant desire to learn and innovate.

🔭 **I’m currently working on:**  
- Building an advanced **RAG (Retrieval-Augmented Generation) System** that integrates OCR, intelligent chunking, embedding models, and local LLMs to create a powerful document querying pipeline.  
- Developing my **B.Sc. Thesis**: a multi-task model for deepfake detection, focusing on identity spoofing and temporal consistency in facial videos.

👯 **I’m looking to collaborate on:**  
- Open-source projects related to efficient vision transformers, federated learning, and privacy-preserving AI.  
- Innovative IoT-AI integrations, especially those deploying models on edge devices like Raspberry Pi.

🤝 **I’m looking for help with:**  
- Optimizing and compressing deep learning models for real-time performance.  
- Advanced techniques in self-supervised and unsupervised learning for computer vision.

🌱 **I’m currently learning:**  
- Deepening my knowledge of **Vision Transformers (ViTs)** and attention mechanisms.  
- Exploring **Adversarial Machine Learning** to make AI models more robust and secure.  
- Practical deployment of models using **NCNN** and other mobile-optimized frameworks.

💬 **Ask me about:**  
- Computer Vision, YOLO, and Object Detection.  
- My journey from hardware tinkering to AI-powered systems.  
- Building projects with Python, PyTorch, and OpenCV.

⚡ **Fun fact:** I started my tech journey by tinkering with hardware long before I wrote my first line of code! I believe in learning by doing, and I apply that mindset to everything I create—from AI-powered robotic arms to decentralized authentication systems.
